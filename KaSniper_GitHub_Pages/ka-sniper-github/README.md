# 蚊スナイパー — 安眠防衛戦

スマホ・PCのブラウザで遊べる、パチンコ式の蚊退治ゲーム。インストールやAPIキー、ビルド作業は不要です。

## GitHubで公開する手順

1. このZIPを展開します。
2. GitHubで新しいリポジトリ（例：ka-sniper）を作ります。
3. 展開したフォルダの**中身**をリポジトリ直下へ入れ、mainブランチへ保存します。`.github/workflows/pages.yml`も必ず含めてください。
4. リポジトリの Settings → Pages → Source を **GitHub Actions** に設定します。
5. Actionsで「Deploy game to GitHub Pages」が成功したら、Settings → Pagesに表示されたURLから遊べます。必要ならActions画面から手動実行してください。

GitHub Desktopを使う場合は、展開した中身をローカルリポジトリへコピーし、Commit → Publish repositoryを行えます。公開リポジトリにするとゲームのソースも閲覧可能になります。

## 操作

- 開始前の「説明あり／説明なし」でヒントの表示を選択。プレイ中も左下から変更可能。
- 下のパチンコの玉を下へ引いて離すと発射。
- 各面4匹でクリア。花瓶や電球に当たるとその面をやり直し。
- 全9面。扇風機、カーテン、飛び方の違いがあります。
- 3面ごとに20秒の草原ボーナス。指やマウスで電撃ラケットを動かします。

## 記録と注意点

- 順位はクリア面数 → 通算命中率 → 通算時間の順です。失敗した面の発射数・撃退数・時間も通算します。
- 草原ボーナスは最高撃退数を別途保存します。
- 保存先は同じブラウザのlocalStorageです。オンライン共通ランキングではありません。ブラウザのデータ削除で記録は消えます。
- Sites版とGitHub Pages版はURLが異なるため、記録や設定は自動移行しません。
- 振動は対応ブラウザのみ。iPhoneでは振動が動かない場合があります。
- 現在の「説明あり」は文字ヒントの表示です。指アニメや仕掛けの実演は未実装です。

## ローカル確認

index.htmlをブラウザで開くか、Pythonがあればこのフォルダで `python -m http.server 8000` を実行し、http://localhost:8000 を開いてください。

## 構成

- index.html：ゲーム本体（画像・音声はコード内で生成）
- .github/workflows/pages.yml：GitHub Pagesへの自動公開
- .nojekyll：静的ファイル配信用

外部API、トラッキング、広告は組み込んでいません。再配布ライセンスは未設定です。
