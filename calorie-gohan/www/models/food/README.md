# 日本の料理用の判定データ置き場

ここに次の2つを置くと、写真の判定にこちらが優先して使われます（スマホの中だけで動きます）。

- `model.json`（と付属の `.bin` ファイル）… TensorFlow.js 形式の画像判定データ（入力 224×224）
- `labels.json` … 判定結果の並びに対応する料理の id の一覧（`js/foods.js` の id）。例：`["rice","curry","ramen", ...]`

置いていない時は、一般的な画像判定（MobileNet）で分かる料理（ピザ・ハンバーガー・バナナなど）だけを当て、
分からない時は料理を選んでもらいます。
