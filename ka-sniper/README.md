# 蚊スナイパー — 安眠防衛戦

スマホ・PCのブラウザで遊べる、パチンコ式の蚊退治ゲーム。インストールやAPIキー、ビルド作業は不要です。

## 公開（GitHub Pages）

このリポジトリには公開用の設定一式が入っています。

1. リポジトリの Settings → Pages → Source を **GitHub Actions** に設定します（初回のみ）。
2. `main` ブランチへ push すると、Actions の「Deploy game to GitHub Pages」が自動で走ります。手動実行も可能です。
3. 成功したら Settings → Pages に表示される URL（通常 `https://<ユーザー名>.github.io/ka-sniper/`）で遊べます。

## 操作

- 開始前の「説明あり／説明なし」でヒント表示を選択。プレイ中も左下から切り替え可能。
- 下のパチンコの玉を下へ引いて離すと発射。
- 各面4匹でクリア。花瓶や電球に当たるとその面をやり直し。
- 3面ごとに20秒の草原ボーナス。指（PCはマウスを動かすだけでもOK）で電撃ラケットを動かします。

## 全9面

| 面 | 仕掛け |
|---|---|
| 1 | 基本の狙い撃ち |
| 2 | 花瓶に注意 |
| 3 | 電球に注意 |
| 4 | 扇風機の風で玉が右へ流れる |
| 5 | カーテンの裏の蚊には当たらない |
| 6 | 蚊は止まっているが、外すと一斉に飛び立つ |
| 7 | ゴムを引くと蚊が左右へ逃げる |
| 8 | 高速の周回飛行 |
| 9 | 親玉（3発で撃退）と取り巻き。休憩の瞬間を狙う |

## 説明あり

- 画面上部に「面の名前」と「攻略のコツ」を表示します。
- 第1夜の最初の1発までは、指でゴムを引く動きを実演します。

## 記録と注意点

- 1プレイ＝1件として記録し、面を進めるたび・失敗するたびに同じ記録を更新します。
- 順位はクリア面数 → 通算命中率 → 通算時間の順です。失敗した面の発射数・命中数・時間も通算します。
- 命中率は「当たった発数 ÷ 発射数」です（親玉への命中も1発として数えます）。
- 草原ボーナスの最高撃退数と、音のON/OFFも保存します。
- 保存先は同じブラウザの localStorage です。オンライン共通ランキングではなく、ブラウザのデータ削除で消えます。
- 振動は対応ブラウザのみ。iPhone では振動しない場合があります。

## ローカル確認

`index.html` をブラウザで開くか、このフォルダで次を実行して http://localhost:8000 を開いてください。

```bash
python3 -m http.server 8000
```

## 構成

- `index.html`：ゲーム本体（画像・音声はコード内で生成）
- `.github/workflows/pages.yml`：GitHub Pages への自動公開
- `.nojekyll`：静的ファイル配信用

外部API、トラッキング、広告は組み込んでいません。再配布ライセンスは未設定です。
